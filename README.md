# Тетрис

Классическая игра «Тетрис» на чистом JavaScript с использованием Canvas.

## Фичи
- Полноценный игровой цикл с частотой 240 кадров/с
- Динамическая скорость падения в зависимости от уровня
- Вращение фигур с коррекцией у стен (kickback)
- Система удержания фигуры (Hold)
- Предпросмотр следующей фигуры
- Тень (ghost piece) — показывает место падения
- Удаление линий с подсчётом очков (бонусы за 2, 3, 4 линии)
- Повышение уровня каждые 10 очищенных линий
- Адаптивный размер ячеек под окно браузера

## Как запустить
Открыть `index.html` в браузере.

Проект написан полностью самостоятельно, без AI-ассистентов (2023 г.)
